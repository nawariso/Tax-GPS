## รายได้และสิทธิเดิม

`BASE` ใช้วันตัดข้อมูล 31 ต.ค. 2569 ที่ยืนยันแล้ว ยอดจริงค่าจ้าง 600,000 บาท (ในตัวอย่างรวมค่าล่วงเวลา 5,000 บาทแล้ว) โบนัส 40,000 บาท ยอดคาดค่าจ้าง 300,500 บาท โบนัส 50,000 บาท ผู้ใช้ยืนยันไม่มีเงินได้นอก coverage ทั้งสองช่วง เป็นผู้มีสิทธิส่วนตัว ยืนยันประกันสังคมจ่ายจริงเป็นศูนย์ และยืนยันไม่มีสิทธิหรือประวัติอื่นตามแบบเดิม หักจริง 45,000 บาทและคาดหักเพิ่ม 30,000 บาท

**วิธีตรวจเลข** สำหรับ BASE รายได้รวม 600,000 + 40,000 + 300,500 + 50,000 = 990,500 ค่าใช้จ่าย 100,000 และสิทธิส่วนตัว 60,000 ตาม pack ให้ฐาน 830,500 ภาษีได้จาก 7,500 + 20,000 + 37,500 + 16,100 = 81,100 จากนั้นลบยอดหักรวม 75,000 เหลือ 6,100

PVD ใช้ผลแยก 20,000 ก่อนค่าใช้จ่ายและ 10,000 หลังค่าใช้จ่ายตามกฎที่ใช้อยู่ ฐานลดลง 30,000 เป็น 800,500 ส่วน RMF ใช้ยอดซื้อจริง 100,000 หลังค่าใช้จ่ายและสิทธิเดิม ฐานเหลือ 730,500 กรณี FRACTION ใช้ claim 297,150.003 และประกันสังคม 10,500 ตาม [fixture C02B `EXACT-DERIVED`](../policy-evidence/2026-10-22/c02b-scope/rmf-reference.json) แล้วลบยอดหัก 30,927.50 ออกจาก PIT 30,927.50105
