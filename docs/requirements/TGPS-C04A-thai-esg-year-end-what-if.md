## เป้าหมาย

ให้พนักงานเงินเดือนที่มีประมาณการภาษีปี 2569 จาก C03 ใส่ **จำนวนเงินที่ตนเลือกเอง** ที่จะซื้อ Thai ESG ภายในปีภาษี แล้วเห็นว่า PIT ทั้งปี ยอดชำระเพิ่มหรือคืน และเงินสดที่เหลือเปลี่ยนไปอย่างไร ระบบแสดงผลของจำนวนที่ผู้ใช้เลือกเท่านั้น ไม่แนะนำ ไม่จัดอันดับ และไม่เลือกกองทุนให้

## ขอบเขต v0.1 ที่เสนอ

- ปีภาษี 2569, มาตรา 40(1), ผลประมาณการต้องมาจาก C03 ที่ baseline `READY` เท่านั้น ถ้า C03 ไม่ READY ให้ปิดส่วนทดลองทั้งหมดตามกฎเดิม
- สิทธิใหม่ที่ทดลองได้มี **Thai ESG อย่างเดียว** หนึ่งจำนวนต่อการคำนวณ จำนวนเป็น `Money` ไม่ติดลบ ละเอียดไม่เกินสตางค์
- RMF ซื้อเพิ่ม, Thai ESGX, ประกัน, โปะหนี้ และการลงทุนทั่วไปอยู่นอก v0.1 (RMF ไป C04B หลังปิดคำถามหลักฐาน PVD ร่วม RMF ตาม DEC-033)
- ไม่มี ranking/recommendation/return forecast/การเลือกกองทุน ข้อความบนจอต้องไม่ชี้นำว่า "ควรซื้อ"

## การคำนวณและสถานะผล

1. **วงเงิน Thai ESG ที่เหลือ** = ค่าน้อยกว่าระหว่าง `30% × เงินได้พึงประเมินทั้งปีจาก C03 (ยอดจริง + ยอดคาด)` กับ `300,000` หักยอดซื้อเดิมตาม D2 อัตราและเพดานอ่านจาก catalog ที่ activate แล้ว ไม่ hard-code ในโค้ด วงเงินเปลี่ยนเมื่อผู้ใช้แก้ยอดคาด
2. **เงินที่ใช้ได้** มาจาก guardrail เดิมตาม D3 ถ้าข้อมูล guardrail ไม่ครบ สถานะส่วนทดลอง = `REQUIRES_INPUT` พร้อมชื่อช่อง
3. เมื่อ C03 `READY`, guardrail อนุญาต และจำนวน ≤ ค่าน้อยกว่าของวงเงินสิทธิกับเงินที่ใช้ได้ ให้คำนวณ `tax_impact(จำนวน)` ได้ **PIT หลังซื้อ** และ **ภาษีที่ลดลง** = PIT เดิม − PIT หลังซื้อ
4. **ยอดชำระเพิ่ม/คืนหลังซื้อ** = PIT หลังซื้อ − ภาษีหัก ณ ที่จ่ายทั้งปี ใช้กฎเดียวกับ C03: ถ้ายอดหักยังขาด แสดง PIT หลังซื้อได้แต่ส่วนต่างเป็น `null` พร้อมชื่อช่องที่ขาด
5. จำนวน 0 ต้องให้ผลเท่ากับ C03 ทุกตัวเลข (PIT, ยอดเพิ่ม/คืน)
6. ลำดับสถานะของส่วนทดลอง: สถานะ C03 ที่ไม่ READY ก่อน → `UNSUPPORTED` (เช่น ยอดซื้อเดิมบวกตาม D2(ก)) → `REQUIRES_INPUT` → ข้อจำกัด (เกินวงเงิน/guardrail) → `READY`

## การแสดงผลและตรวจย้อนหลัง

- หน้าผลภาษาไทยแสดงคู่ "ก่อน / หลังซื้อ Thai ESG จำนวนที่เลือก": PIT ทั้งปี, ยอดชำระเพิ่มหรือคืน, เงินสดที่จ่ายออก และวงเงินสิทธิที่เหลือ
- แสดงเงื่อนไขจาก catalog กำกับผลเสมอ: ต้องซื้อภายในปีภาษี 2569, ถือครองขั้นต่ำ 5 ปีตาม `lockup_metadata`, ต้องมีหลักฐานการซื้อ, เป็นประมาณการภายใต้ยอดคาดของ C03 ห้ามเพิ่มวันตัดรอบหรือเงื่อนไขอื่นที่ไม่มีแหล่งอ้างอิงใน catalog
- แก้ยอด C03 หรือจำนวนทดลองแล้วผลและ export เก่าหมดอายุทันที การตอบกลับเก่าใช้แทนไม่ได้
- Export เพิ่มจาก snapshot C03: จำนวนทดลอง, วงเงินที่ใช้, สถานะ guardrail, PIT ก่อน/หลัง, ส่วนต่างก่อน/หลัง และ provenance ของ catalog/rule/source; replay ต้องตรวจ catalog hash และผลซ้ำ
- ไม่ log หรือใส่ยอดที่กรอกใน error; deterministic, standard library, loopback เท่านั้น

## หลักฐานที่ต้องปิดก่อนเขียนแผน

- **E1** ตรวจแหล่ง `SEC-THAI-ESG-2026` ซ้ำด้วย skill `tgps-policy-evidence`: เอกสาร SEC Q&A ชุดที่ 1 ลงวันที่ 1 เม.ย. 2568 ต้องครอบคลุมปีภาษี 2569, อัตรา 30%, เพดาน 300,000, ถือ 5 ปี, การใช้ pool ร่วมกับ Thai ESGX และการไม่อยู่ในวงเงินเกษียณร่วม (สำหรับ D1) หาแหล่งกฎหมายชั้นต้นของกรมสรรพากร (กฎกระทรวง/ประกาศ) ถ้าหาได้ ถ้ายืนยันไม่ได้ให้รายงานและคงส่วนทดลองปิด (fail closed) ห้ามเดา
- **E2** ไม่เพิ่มตัวเลขกฎหมายใหม่ใน v0.1 ถ้าต้องการวันตัดรอบซื้อของ บลจ. หรือเงื่อนไขอื่น ต้องมีแหล่งและออก catalog version ใหม่ ห้ามแก้ `@1.2.0`
