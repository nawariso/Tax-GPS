# รีวิว PVD ร่วม RMF สำหรับขอบเขต MVP

วันที่ตรวจ 24 พฤศจิกายน 2569 (Asia/Bangkok)

สถานะ `REQUIREMENT_REVIEW` · หลักฐานยังไม่พอสำหรับเปิดผลคำนวณกรณีร่วม

ขอบเขตที่ตรวจคือพนักงานเงินเดือน 40(1) นายจ้างเดียว มีกองทุน PVD ปกติและซื้อ RMF ด้วยเงินตนเองครั้งแรกในปีเดียวกัน โดยใช้ข้อเท็จจริงของ C02A และ C02B เป็นจุดตั้งต้น ประเด็นอยู่ใน C02-AC05 และ AC07 ของ [requirement C02](../../requirements/TGPS-C02-existing-rights.md)

## ผลต่างของสองสมมติฐาน

ใช้ตัวเลขสมมติและคำนวณด้วย `Decimal` แยกจาก engine ตามวิธีใน [ชุดวินิจฉัยเดิม](../2026-10-21/joint-follow-up/diagnostic-cases.json) ทั้งสองกรณีสมมติค่าจ้างฐาน PVD เท่าเงินเดือน ไม่มีสิทธิอื่นในวงเงินเดียวกัน และใช้ค่าประกันสังคมสมมติ 10,500 บาท ค่าลดหย่อนส่วนตัวสมมติ 60,000 บาท ตัวเลขในตารางใช้แสดงผลของการเลือกสมมติฐาน

| เงินเดือน / เงินสะสม PVD / ค่าซื้อ RMF (บาท) | ฐานก่อนหักส่วนยกเว้น PVD · RMF / PIT | ฐานหลังหักส่วนยกเว้น PVD · RMF / PIT |
| --- | ---: | ---: |
| 990,500 / 100,000 / 300,000 | 297,150 / 19,785 | 270,150 / 22,485 |
| 2,100,000 / 300,000 / 300,000 | 200,000 / 222,375 | 200,000 / 222,375 |

กรณีแรกภาษีต่างกัน **2,700 บาท** ส่วนกรณีที่สองวงเงินร่วมเป็นตัวจำกัดก่อนเพดานตามฐานเงินได้ จึงได้ผลเท่ากันทั้งสองสมมติฐาน เคสที่ผลตรงกันอย่างเดียวแยกคำตีความไม่ได้

ภายใต้สัญญา C02A ปัจจุบัน เมื่อค่าจ้างและอัตราสะสมอยู่ในขอบเขตที่รองรับ ยอด PVD ที่จ่ายและยอด PVD ที่ใช้สิทธิรวมเท่ากันจนถึงเพดาน หลังเพดาน ทั้งสองวิธีให้วงเงินคงเหลือเป็นศูนย์สำหรับ **เคสที่มีเฉพาะ PVD และ RMF** ข้อนี้เป็นผลทางเลขคณิตจากขอบเขตเดิม ประเด็น G4 สำหรับยอดที่ไม่เข้าเงื่อนไข สิทธิชนิดอื่น และการจัดสรรเมื่อเกินเพดานยังต้องรีวิวแยก

## ข้อเสนอให้ตัดสินขอบเขต

คงกรณี PVD ร่วม RMF ไว้นอกขอบเขตที่แสดงผลของ MVP แรก จนกว่าจะตรวจได้ว่าข้อ 4 ของคำชี้แจงปี 2559 ใช้กับประกาศ 401 ข้อ 5 ในปี 2569 ได้ หรือพบหลักฐานปัจจุบันที่ตอบโดยตรง ใช้โจทย์ 990,500 / 100,000 / 300,000 ชี้ความต่างของฐาน แล้วทบทวนตัวอย่างทั้งแบบที่ติดเพดานตามฐานเงินได้และแบบที่ติดวงเงินร่วม

ข้อเสนอนี้รอการตัดสินขอบเขต MVP ส่วนกรณี PVD ร่วม RMF ในเดโมยังอยู่สถานะ `UNSUPPORTED` ตาม domain ปัจจุบัน และ G3/G4 ยังเปิดอยู่
